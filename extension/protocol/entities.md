# 记忆库协议 — 实体

实体文件位于 `.memory/entities/`，一个 `<id>.md` 一张实体。操作实体前请先读本手册。

## 库结构

```
.memory/
├── entities/          # 实体：<id>.md 一张
└── verifications/     # 验证记录：<实体id>/<日期>[-N].md，按实体归位、只追加
```

目录骨架由扩展预建，直接读写文件即可（追加验证记录前，实体子目录不存在则创建）。
`.memory/` 是个人运行时数据（gitignore），任何变更绝不提交。

## front-matter（恰好四字段）

文件名即 id：任意非空单行文本（不含换行/制表符/路径分隔符）。格式不合规的文件
（front-matter 缺失或损坏、缺 id/kind）会被扩展忽略。

| 字段 | 取值 | 说明 |
|---|---|---|
| id | 与文件名一致 | 唯一标识 |
| kind | tool / person / project / concept / decision | 类型 |
| sources | URL / 本地路径 / 会话引用 | 出处，多条以 `；` 分隔，不重复 |
| depends-on | 可选；仓库内相对路径逗号分隔（如 `extension/auto.ts`） | 只列直接影响断言的文件，不列间接依赖 |

## 正文规则

- 每句一个独立可验证断言，编号开头：`A1: <断言>`、`A2: …`；编号递增绝不复用，修正落点按编号定位。
- 断言用具体词（grep 可命中），不用代词与模糊措辞（"可能"、"我认为"）；不确定的内容写进 `sources`，绝不进正文。
- 断言自洽：不引用、不比较其他实体的正文。
- 正文不承载信任状态：信任由最新验证记录实时推导（门控见 verifications.md）。
- 描述本仓库代码/配置行为的实体填 `depends-on`：这些文件在最新一次 passed 之后被改过，实体自动降为 stale（扩展实时推导，无缓存文件）。
